Python Data Cleaning and Exploratory Data Analysis (EDA)
Project Overview
This project demonstrates the complete process of cleaning and analyzing a messy dataset using Python and Pandas.

The objective is to transform raw data into a clean, analysis-ready dataset by handling missing values, removing duplicates, correcting data types, and performing exploratory data analysis (EDA).
