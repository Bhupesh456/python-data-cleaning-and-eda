# 📁 Data

This folder contains the datasets used in this project.

## Files

### 📄 Uncleaned_practice.csv
The original raw dataset used for this project. It contains data quality issues such as missing values, duplicate records, inconsistent formatting, and incorrect data types.

### 📄 cleaned_data.csv
The cleaned version of the dataset after performing data preprocessing using Python and Pandas. The dataset has been cleaned by handling missing values, removing duplicates, correcting data types, and standardizing the data, making it ready for analysis.

## Purpose

The datasets in this folder demonstrate the complete data cleaning workflow, from raw data to a clean, analysis-ready dataset.
